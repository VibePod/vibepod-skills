# vibepod-skills

Curated skills for the [VibePod](https://vibepod.dev) skill subsystem. Install any of these via the [`vp skills`](https://github.com/VibePod/vibepod-cli) CLI:

```bash
vp skills add github:vibepod/vibepod-skills//skills/researcher
vp skills add github:vibepod/vibepod-skills//skills/summarizer#0.1.0
```

## Skills

| ID          | Description                                              |
|-------------|----------------------------------------------------------|
| researcher  | Investigate a topic, follow links, and produce a brief.  |
| summarizer  | Compress long inputs into structured key-points.         |
| transcript  | Turn recorded audio/video into a clean transcript.       |
| podcast     | Plan, script, and produce a short podcast episode.       |
